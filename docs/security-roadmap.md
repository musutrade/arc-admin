# 安全能力待办

## `super_admin` 多因素认证

- [ ] 状态：待实现。生产环境启用 `super_admin` 前必须完成，当前版本不宣称已支持 MFA。
- [ ] 注册：支持 WebAuthn 安全密钥或通行密钥，并提供 TOTP 兼容方案；敏感材料加密存储，恢复码只保存哈希。
- [ ] 登录：密码校验后进入独立二次验证阶段，未通过前不得签发完整认证会话；二次验证失败需单独限流。
- [ ] 强制策略：所有 `super_admin` 强制注册并验证，不允许通过记住设备、密码重置或管理员接口绕过。
- [ ] 恢复与撤销：恢复流程需要高强度重新认证，撤销因子和使用恢复码后立即撤销该用户全部会话。
- [ ] 审计：记录注册、验证成功/失败、因子撤销、恢复码使用和策略变更，不记录密钥、验证码或恢复码原文。
- [ ] 验收：补齐迁移、后端接口、Angular 管理界面、OpenAPI 契约、集成测试和生产运维说明后，才能关闭本项。
